Checkout: `./scripts/setup-environment.sh` (git submodules + root `bun install`—not Google `repo`); day-to-day: lazygit (`U` / `P`). Toolchain: `scripts/install-deps.sh` + `repo-deps.json`. CI: `beskid-platform` → `container-images` with `secrets: inherit` so `NODE_AUTH_TOKEN` reaches npm/docker steps; Dagger in `beskid_infra/dagger/`, root `dagger.json`.
- **Shared npm packages:** Consumers use `npm:@cyber-nomad-collective/...@^0.2.0` aliases plus per-app `.npmrc` (`@beskid` + `@cyber-nomad-collective` → `npm.pkg.github.com`).
