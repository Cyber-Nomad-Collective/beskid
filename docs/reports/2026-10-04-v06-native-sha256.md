FIPS 180-4 specifies SHA-256 with 32-bit words, 512-bit blocks and a 256-bit output; byte-oriented padding appends a one bit, zeros and the original 64-bit big-endian length. Compression uses modular word sums, rotations, choice/majority and 64 rounds. Implementation follows sections 4.1.2, 4.2.2, 5.1.1, 5.2.1, 5.3.3 and 6.2. Process input through 64-byte blocks and one/two final padding blocks, without making a full padded input copy. [NIST FIPS 180-4](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf).
