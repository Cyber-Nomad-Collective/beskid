# Approved Dynamic V1 migration

Runtime ABI 5 retains its 64-byte RuntimeState and 40-byte BeskidTypeDescriptor. Dynamic cells are descriptor-validated GC allocations of 40 bytes, alignment 8: descriptor at 0, collector state at 8, managed payload at 16, managed ShapeRecord at 24, nonzero process-local tag at 32. The cell pointer map traces offsets 16 and 24. Descriptor reserved word 36 is not shape identity.

The internal callback registry becomes explicitly versioned V3, size 1072, shared with the checked Glue ownership authority. Existing offsets 0–1055 remain unchanged; offset 1056 owns a Dynamic registry root handle and offset 1064 owns the Glue owner-record root handle. This supersedes the initial V2-only allocation plan. Replacement copies both root handles without changing ownership. Startup and rollback initialize/clear both; shutdown unroots both before HandlesClear and frees the allocation using its actual schema size. No RuntimeState field or composition pointer is repurposed.

RegisterShapeV1 consumes compiler-emitted canonical metadata, not a test-authored serialized signature. Its bounded closure includes canonical nominal identity, generic substitutions, ordered field names/types, managed-reference ownership, exact scalar width/signedness, canonical layout and pointer map, and a stable signature digest. The existing generation-bound ModSemanticAuthority issues semantic facts; emitter construction consumes those facts and existing canonical layout queries. Invocation-local handles must not escape issuer lifetime. Registry ownership retains validated runtime metadata, not syntax handles or a parallel semantic cache. Cycles, incomplete registration, collisions and invalid layouts fail closed. Limits are explicit registration inputs and checked before allocation/publication.

RegisterMappingV1 registers source/destination shapes and a canonical typed mapping artifact. CreateV1(value,shapeHandle), CastV1(cell,shapeHandle), and MapV1(cell,mappingHandle) return checked Results. Tokens are owner/generation checked, never serialized GC addresses. Map allocates a fresh destination, validates every field, roots temporaries, applies canonical barriers and publishes only on success. AOT and runtime-known mapping consume equivalent registered plans. No ignored mapping, descriptor-to-shape compatibility fallback or raw source-payload success remains. Replace old internal declarations and call sites together. Runtime manifest/export schema explicitly records the migration; old C symbols cannot silently retain obsolete semantics.

## Native prerequisite gate

DynamicV1Tests is deliberately blocked on the absent DynamicFixtureMetadata module and V1 APIs. That module must be generated from the declared fixture types by the production Serialization Mod structural backend, using ModSemanticAuthority. It must not be implemented by a handwritten signature, copied descriptor bytes or fake compiler handle. The tests are source fixtures, not observed runtime proof until the fresh candidate executes them.

Generated fixture API: RegisterSourceShapeV1 and RegisterDestinationShapeV1 return checked shape tokens; RegisterSourceToDestinationV1 returns the checked typed mapping token; AllocateSourceV1(value) returns a managed source pointer, ReadSourceValueV1 and ReadDestinationValueV1 use generated canonical field access. These are fixture adapter contributions emitted through the same production backend, not a second shape authority.

Runtime services: DynamicRegisterShapeV1, DynamicRegisterMappingV1, DynamicCreateV1, DynamicCastV1, DynamicMapV1 return Result values; exact exported C transport DTOs/error discriminants must be frozen in the runtime manifest before implementation. Positive tests require cell-only rooting and forced collection, fresh transformed mapping and unchanged source. Negative tests require zero/stale handles and invalid mapping rejection. Further gates cover process restart, signature collisions, invalid pointer maps, managed nested fields, allocation failures, callback replacement and owner release at shutdown.

Root runs candidate test --plain --json --project runtime/beskid/tests/runtime_semantics --target DynamicV1Tests --target-timeout 120 from compiler with the newly installed corelib and matching native runtime prefix. First missing-emitter/API failure is prerequisite RED only; it is not collector execution evidence.
