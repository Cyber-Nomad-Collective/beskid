# Beskid 0.5.1 Line-Oriented CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove `beskid hi` and all other full-screen terminal interfaces except `beskid graph --tui`, while preserving useful progress bars, phase trees, prompts, and REPL operation.

**Architecture:** Make ordinary command output a line-oriented observer with optional bounded in-place TTY progress. Keep graph's independent terminal runtime behind its explicit `--tui` path. Delete dead Hi shell and exclusive UI dependencies after callers migrate; no compatibility alias.

**Tech Stack:** Rust (`beskid_cli`, `beskid_tools`, `beskid_repl`), Clap, PTY integration tests.

**Spec:** `docs/superpowers/specs/2026-10-01-beskid-051-cli-interaction.md` and canonical OpenSpec CLI specs.

## Global constraints

- Base compiler work on `origin/main` at or after `44a07aed`, not the stale root checkout. Do not edit the template engine paths owned by the separate template-generation plan.
- No GitNexus, push, merge, publication, user-project deletion, or credential access.
- Focused Linux builds only on the NixOS builder, with at most four heavy jobs total. Do not run heavy builds on the Mac. Mention `scripts/diagnose/` and `docs/diagnose.md` in debugging prompts; report if absent.
- TDD: capture an actual failing test before each behavior fix. Preserve graph's explicit TUI.

## Review focus

- `beskid hi` absent from help and dispatch; unknown command fails without alternate-screen escape codes.
- No ordinary command enables raw mode, enters alternate screen, or waits for Space/q after completion.
- `--plain` and pipes are newline-only; TTY progress bars are bounded and final phase tree/summary readable.
- `new` prompts are line-oriented; confirmed overwrite is handled by the template-generation plan and must not be duplicated here.
- `graph --tui` still renders; Mermaid and file-output alternatives still work.
