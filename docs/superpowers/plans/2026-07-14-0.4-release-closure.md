# 0.4 HIR-Free ABI-v5 Release Closure Plan

> **For agentic workers:** Use `superpowers:subagent-driven-development`, run a GitNexus impact analysis before editing a symbol, write tests before implementation, and commit one focused task at a time.

**Goal:** Close the 0.4 compiler release only after every active production path is HIR-free, lowers through ISLE to verified stock CLIF, and uses an exact canonical ABI-v5 Beskid runtime kit.

**Constraints:** Preserve the authoritative expanded AST/Salsa facts, `CodegenInput`, `runtime_manifest.bsol`, two assembly context exports, ABI-v5 target set, and deterministic kit metadata. No compatibility fallback may keep an HIR, `Lowerable`, or Rust runtime path alive.

## Wave 1 — replacement authorities (parallel)

1. **Production codegen adapter**
   - Files: `compiler/crates/beskid_codegen/**`, `compiler/crates/beskid_isle/**`, adapter tests.
   - Map `CodegenInput` typed syntax and Salsa facts into ISLE terms; add a parsed-source-to-verified-CLIF integration test.
   - Verify: `cargo test -p beskid_codegen --all-targets` and `cargo test -p beskid_isle --all-targets`.

2. **Semantic facts closure**
   - Files: `compiler/crates/beskid_queries/**`, query fixtures/tests.
   - Add generation-safe capture, spawn, and trusted-runtime-intrinsic facts with diagnostics and spans.
   - Verify: `cargo test -p beskid_queries --tests -- --test-threads=1`.

3. **Exact runtime-kit cleanup**
   - Files: `compiler/crates/beskid_aot/**`, AOT tests.
   - Remove prebuilt/standalone/legacy resolver compatibility and prove only exact ABI-v5 kits are attachable.
   - Verify: `cargo test -p beskid_aot --all-targets`.

## Wave 2 — consumer migration (after Wave 1 integration)

4. **Complete ISLE coverage and codegen entry migration**
   - Files: `compiler/crates/beskid_isle/**`, `compiler/crates/beskid_codegen/**`.
   - Use the new facts for lambdas, captures, spawn, runtime intrinsics, aggregates, and item bodies; delete production `Lowerable` and HIR linker entry points.
   - Verify: `cargo test -p beskid_isle --all-targets`, `cargo test -p beskid_codegen --all-targets`, and the full coverage inventory test.

5. **Syntax/Salsa frontend and LSP migration**
   - Files: frontend/project assembly and `compiler/crates/beskid_lsp/**`.
   - Replace HIR-backed document services with syntax indexes and semantic facts; verify stale generations cannot resolve.
   - Verify: `cargo test -p beskid_lsp --lib -- --test-threads=1` plus document/query suites.

6. **Canonical runtime completion**
   - Files: `compiler/runtime/beskid/**`, ABI/runtime-kit build and target assembly tests.
   - Compile the canonical source corpus into exact debug/release kits; implement only trusted intrinsics and approved context exports.
   - Verify: ABI/runtime capability and installed-prefix kit tests for the supported target/profile matrix.

## Execution ledger — 2026-07-14 parallel pass

| Domain | Owner | Exclusive scope | Required evidence | Unblocks |
| --- | --- | --- | --- | --- |
| Production ISLE migration | codegen worker | `beskid_codegen`, `beskid_isle` | parsed-source → `CodegenInput` → verified CLIF tests and coverage inventory | legacy `Lowerable` deletion |
| Canonical runtime and kit matrix | runtime worker | `runtime/beskid`, `beskid_abi`, runtime-kit tooling | runtime source/capability tests and manifest-validated kit test | three-target installed-prefix smokes |
| LSP syntax authority | LSP worker | `beskid_lsp` only | per-feature regression with no HIR analysis snapshot | LSP HIR-service deletion |

Workers MUST NOT edit another row's scope or run workspace-wide formatting. The integrator reviews each focused commit, runs its acceptance command after integration, and only then starts the dependency-unblocked deletion work.

## Wave 2b — complete remaining authorities (parallel after the first Wave 2 commits)

7. **Runtime corpus and target/profile matrix**
   - Implement lifecycle, traps, TLS, allocation, GC, roots/barriers, strings, collections, scheduler, composition, clocks, callbacks, and OS adapters in canonical Beskid source.
   - Build static/shared debug and release kits for every supported target, validate exact metadata/source hashes, and run empty-prefix JIT/AOT smokes.

8. **Full ISLE inventory and consumer cutover**
   - Cover all typed operations, including items, aggregate layout, closures/captures, spawn, and trusted intrinsics; migrate JIT/corelib/CLI onto the sole `CodegenInput` route.
   - Keep unsupported operations as deterministic span diagnostics; never reintroduce an HIR fallback.

9. **Remaining LSP/document services**
   - Migrate hover, references, completion, diagnostics, refresh, and document rendering independently where their syntax/Salsa facts are available.
   - Each handler needs a no-legacy-snapshot regression before its old service is deleted.

## Missing-facts execution wave

1. **Completion candidate authority**
   - Add generation-safe Salsa facts for lexical, imported, receiver/member, and type candidates, including deterministic ranking and replacement spans.
   - Reproduce existing completion fixtures with `Document.analysis = None`; do not delegate to `completion_candidates`.

2. **Syntax semantic-token authority**
   - Derive token kind, modifiers, and ranges from generation-bound syntax indexes and semantic facts rather than document-analysis symbols.
   - Preserve LSP legend ordering and encoded token deltas; add a no-analysis token regression.

3. **Non-forgeable canonical-runtime assembly authority**
   - First migrate `SyntaxProgramAssembly` public literals to an authority-free normal constructor/builder.
   - Then add an ABI-owned opaque canonical-runtime factory, carry the proof through `TypedProgram` and `CodegenInput`, and gate manifest intrinsic calls/imports on it.
   - Tests must demonstrate that a normal project cannot forge the proof by path, logical name, source content, or public construction.

## Wave 3 — deletion and release gates (sequential)

7. **Remove retired implementation paths**
   - Delete HIR/lowering/cache/adapters, bridge/host/Rust-runtime linkage, old ABI dispatch, and obsolete dependencies only once Waves 1–2 callers have moved.
   - Verify: `compiler/scripts/verify-hir-free-abi-v5.sh` and an object/binary Rust-provenance audit both report zero violations.

8. **Release verification and documentation**
   - Run fresh focused gates, `cargo test --workspace --all-targets`, corelib and installed-prefix smokes, actionlint/package checks, GitNexus changed-scope analysis, and a whole-branch review.
   - Update `CHANGELOG.md`, `GLOSSARY.md`, `GUIDE.md`, OpenSpec tasks, implementation anchors, and release evidence with commands and results. Do not claim 0.4 complete unless all gates are green.

## Integration rule

No deletion task starts merely because a replacement compiles. It starts only after all live callers have moved, its scoped suites are freshly green, and the retirement scan identifies that path as the next isolated blocker. Final status requires a freshly green full workspace, three-target debug/release installed-prefix matrix, zero retired-pattern/provenance violations, and whole-branch review.
