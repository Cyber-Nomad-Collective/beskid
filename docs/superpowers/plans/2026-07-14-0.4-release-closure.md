> **For agentic workers:** Use `superpowers:subagent-driven-development`, run a GitNexus impact analysis before editing a symbol, write tests before implementation, and commit one focused task at a time.

**Goal:** Close the 0.4 compiler release only after every active production path is HIR-free, lowers through ISLE to verified stock CLIF, and uses an exact canonical ABI-v5 Beskid runtime kit.

**Constraints:** Preserve the authoritative expanded AST/Salsa facts, `CodegenInput`, `runtime_manifest.bsol`, two assembly context exports, ABI-v5 target set, and deterministic kit metadata. No compatibility fallback may keep an HIR, `Lowerable`, or Rust runtime path alive.

## Integration rule

No deletion task starts merely because a replacement compiles. It starts only after all live callers have moved, its scoped suites are freshly green, and the retirement scan identifies that path as the next isolated blocker. Final status requires a freshly green full workspace, three-target debug/release installed-prefix matrix, zero retired-pattern/provenance violations, and whole-branch review.
