<SpecSection title="Scope" id="scope">
This **language-meta area** defines:

- The **`Mod` project type** — how a manifest declares a compiler-mod package that is discovered from the dependency graph and participates in compilation orchestration (see **[Project manifest contract](/platform-spec/tooling/manifests-and-lockfiles/project-manifest-contract/)** for schema).
- The **Beskid Compiler Mod SDK** surface — declarative collection/query contracts and typed AST operations used by `Collector`, `Generator`, `Analyzer`, `Rewriter`, and `AttributeGenerator`.

**Rust-side implementation** — mod host execution, AOT artifact lifecycle, merge, diagnostics transport, and incremental invalidation — is specified under **[Compiler Mods](/platform-spec/compiler/compiler-mods/)**.
</SpecSection>

- **[Serialization packages](/platform-spec/language-meta/metaprogramming/serialization/)** — Serialization Mod, Serialization library, and format packages.
