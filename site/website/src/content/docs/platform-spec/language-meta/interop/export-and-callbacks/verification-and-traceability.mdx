## Spec-first

v0.3 **Standard** text for export/callbacks precedes full codegen and linker support.

## Required fixtures (when implemented)

| Fixture | Asserts |
| --- | --- |
| Valid `[Export]` on `pub fn` | Parses; types check |
| `Export` on contract/type | Diagnostic |
| Callback table version mismatch | Host registration error path |
| Link exports + runtime archive | Symbol present in final binary |

Runtime tests **may** use `#[ignore = "v0.3 export impl"]` until link drivers emit export metadata.

## Runtime ABI

Adding **user export symbols** **must not** change `RUNTIME_EXPORT_SYMBOLS` unless a new **runtime-provided** registrar is promoted to the Rust ABI profile.
