<SpecSection title="What this feature specifies" id="what-this-feature-specifies">
The **`packageKind`** field on **`beskid.package.v1`** — discriminates **library**, **template**, and reserved **tool** packages for validation and registry UI.
</SpecSection>

<SpecSection title="Implementation anchors" id="implementation-anchors">
- `pckg/src/Server/Services/PackageArtifactValidator.cs` — per-kind validation
- `pckg` package routing and dashboard
- Pack/upload in `compiler/crates/beskid_pckg` and workspace publish services
</SpecSection>

<SpecSection title="Contract statement" id="contract-statement">
Every published **`beskid.package.v1`** artifact **must** declare its role through **`packageKind`**. Kinds drive validator profiles, registry UI routing, and CLI behavior. **`project.type`** on `Project.proj` is the **project-tree** analogue (`Host`, `Mod`, `Template`, …); **`packageKind`** is the **registry artifact** analogue—they are related but not interchangeable.
</SpecSection>

<SpecSection title="Normative kinds" id="normative-kinds">
| `packageKind` | Purpose | API docs on pckg | Primary CLI |
| --- | --- | --- | --- |
| **`library`** (default) | Beskid source package consumed as dependency | **Required** when server policy mandates `api.json` | `beskid pckg pack`, consumer `beskid fetch` |
| **`template`** | Scaffold package for `beskid new` | **Hidden** — template page only | `beskid new install`, `beskid new <shortName>` |
| **`tool`** | Reserved — CLI/tool binaries distributed via pckg (future) | TBD in future feature | TBD |

Unknown `packageKind` values **must** be rejected at publish time.
</SpecSection>

<SpecSection title="Project.type alignment" id="project-type-alignment">
| `project.type` | Typical `packageKind` when published |
| --- | --- |
| *(absent)* / `Host` | `library` |
| `Mod` | `library` |
| `Template` | `template` |

A **`library`** package **must not** publish with `type: Template` on `Project.proj`. A **`template`** package **must** include `.beskid/template.json`.
</SpecSection>

<SpecSection title="Versioning" id="versioning">
All kinds share: registry-assigned publish semver, immutability per version, yank, checksum verification, and download URLs.
</SpecSection>
