<SpecSection title="What Bsol is" id="what-bsol-is">
**Bsol** (Beskid Structured Object Language) is the shared meta-language for Beskid manifest files: block-oriented assignment syntax used by **`*.bproj`** project manifests and **`*.bws`** workspace manifests.

Bsol specifies **lexical rules**, **surface grammar**, and the **reference AST**. Manifest **semantics** (required keys, project kinds, Mod blocks, link metadata) remain in sibling **[Project manifest contract](/platform-spec/tooling/manifests-and-lockfiles/project-manifest-contract/)** and **[Workspace and lock contracts](/platform-spec/tooling/manifests-and-lockfiles/workspace-and-lock-contracts/)**—those features lower a Bsol AST into typed models and apply contract validation.
</SpecSection>
