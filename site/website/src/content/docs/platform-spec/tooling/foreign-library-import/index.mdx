<SpecSection title="What this feature specifies" id="what-this-feature-specifies">
**Foreign library import** connects Beskid **`Extern(..., Library:"...")`** logical names to **platform linker inputs** for v0.3 **link-time** FFI.

It specifies:

- The **`ExternalLibrary`** provider trait (Rust tooling) for per-platform / per-language resolution.
- A **`beskid import lib`** (exact CLI name reserved) command for mapping and importing libraries into project manifests.
- Interaction with **[project link libraries](/platform-spec/tooling/manifests-and-lockfiles/project-manifest-contract/project-link-libraries/)**.
</SpecSection>

<SpecSection title="v0.3 scope" id="v03-scope">
| In scope | Deferred |
| --- | --- |
| C / POSIX library providers on tier-1 hosts | WinAPI stdlib providers |
| Manifest `link` block population from CLI | Automatic C header parsing |
| Closed provider registry in CLI | Third-party provider plugins (future) |

Implementation in `beskid_cli` may trail spec; conformance is documented in article verification sections.
</SpecSection>

<SpecSection title="Implementation anchors" id="implementation-anchors">
- Planned: `compiler/crates/beskid_cli/src/commands/` (import lib subcommand)
- Manifest parse/validate: `compiler/crates/beskid_analysis/src/projects/`
- Link driver integration: AOT / JIT link pipelines (see **[link-time linking](/platform-spec/language-meta/interop/c-abi-profile/link-time-linking/)**)
</SpecSection>
