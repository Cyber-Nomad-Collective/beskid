<SpecSection title="Rationale" id="rationale">
Tooling must be **specified** so different editor plugins, CI images, and third-party drivers agree on flags,
file formats, and protocol extensions without reverse-engineering the reference implementation.
</SpecSection>

<SpecSection title="Background" id="background">
Informative CLI and workflow reference remains in [the Beskid Book](/book/reference/cli/). This domain will absorb normative `spec/` chapters such as
project lockfile and workspace manifest formats as they are promoted from legacy paths.
</SpecSection>

<SpecSection title="Feature index" id="feature-index">
Top-level tooling features (including **[foreign library import](/platform-spec/tooling/foreign-library-import/)** for v0.3 FFI) appear alongside area hubs below. **[Project scaffolding](/platform-spec/tooling/project-scaffolding/)** defines **`beskid new`**, template packages, and **`packageKind: template`**.
</SpecSection>
