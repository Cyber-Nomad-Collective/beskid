<SpecSection title="What this feature specifies" id="what-this-feature-specifies">
The **Beskid auth hub** (`site/auth/`) is the single **GitHub OAuth** authority for platform web apps. Consumers (**Tracker**, **Nexus**, **pckg**) **must not** register separate GitHub OAuth apps. They pair once with the hub, store a per-app **service token**, and complete sign-in through a **handoff JWT** issued by issuer **`beskid-auth-hub`**.

GitHub access tokens remain on the hub. TypeScript consumers call GitHub through **`/api/v1/github/*`** using the handoff token (`hubUserToken`).
</SpecSection>

<SpecSection title="Consumers" id="consumers">
| App id | Sign-in entry | Hub finish | Pairing (admin) |
| --- | --- | --- | --- |
| `tracker` | `/api/auth/github` | `/api/auth/hub-finish` | `/settings/auth/pair` (autopair when `TRACKER_PUBLIC_URL` is set) |
| `nexus` | `/api/auth/github` | `/api/auth/hub-finish` | `POST /api/admin/auth/pair` or setup wizard |
| `pckg` | `/api/auth/github` | `/api/auth/hub-finish` | `POST /api/auth/hub/pair` |

Pairing `publicUrl` **must** be the consumer origin (for example `https://tracker.beskid-lang.org`). The hub redirects handoff to `{publicUrl}/api/auth/hub-finish?handoff=…`.
</SpecSection>
