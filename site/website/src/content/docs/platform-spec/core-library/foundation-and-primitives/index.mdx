<SpecSection title="Rationale" id="rationale">
`corelib_foundation` hosts the unified `Core.*` namespace: primitive modules (`Core.Bytes`, `Core.Encoding`, `Core.Text.*`, [Core.Optional](/platform-spec/core-library/foundation-and-primitives/core-optional/)), [Collections](/platform-spec/core-library/foundation-and-primitives/core-collections/), and OS-backed surfaces ([Core.Syscall](/platform-spec/core-library/stability-and-api-shape/core-syscall/), [Core.Time](/platform-spec/core-library/stability-and-api-shape/core-time/)). Stability is expressed with `@tier(...)` and documented builtin backing—not a separate `System.*` namespace. Text parsing primitives are specified under [Text and parsing](/platform-spec/core-library/text-and-parsing/).
</SpecSection>
