<SpecSection title="Rationale" id="rationale">
Pure Beskid primitive modules (`Core.Bytes`, `Core.Encoding`, `Core.Text.*`) live in `corelib_foundation`. They **must not** embed OS syscall semantics; binary I/O routes through [System.Syscall](/platform-spec/core-library/stability-and-api-shape/system-syscall/). Text parsing primitives are specified under [Text and parsing](/platform-spec/core-library/text-and-parsing/).
</SpecSection>
