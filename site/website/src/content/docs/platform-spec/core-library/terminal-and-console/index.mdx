<SpecSection title="Scope" id="scope">
Terminal-facing corelib splits **byte stream I/O** (`Core.Input`, `Core.Output`, `Core.Error` via `Core.Syscall`) from **styled terminal output** (`corelib_console`: `Ansi`, `Console.Format`, controls, capabilities). Resize and tick delivery use **channels** or same-fiber **events**—no new runtime builtins beyond existing syscall and fiber surfaces.
</SpecSection>
