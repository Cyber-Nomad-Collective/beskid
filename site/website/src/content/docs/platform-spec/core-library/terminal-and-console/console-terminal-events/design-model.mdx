## What this article covers
This article documents **design-model** for **Console terminal events**.

## Normative notes
See the parent feature hub and `ANSI.md` in the aggregate repository for escape-sequence tables. Stream I/O must use `System.Syscall` wrappers; stdout/stderr are write-only at the syscall layer.

## Fiber and Channel delivery

Terminal resize, tick, and other asynchronous terminal signals **must** be published to a **`Channel<T>`** (or consumed through a **`Hub`** registration) so the UI fiber can **Receive** them without cross-fiber **`event`** invocation.

- Producer side (platform extern callback or reader fiber): **Send** into the channel.
- Consumer side (main UI loop fiber): **Receive** / **Hub.WaitReceive**.
- **`Console.OnResize`** may remain a typed surface that documents which **Channel** carries `ConsoleSize` payloads.

This aligns with **[Events](/platform-spec/language-meta/evaluation/events/)** fiber-affinity rules and **[Concurrency package](/platform-spec/core-library/concurrency/concurrency-package/)**.
