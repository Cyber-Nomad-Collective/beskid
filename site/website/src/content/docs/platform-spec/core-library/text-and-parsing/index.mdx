<SpecSection title="Area contract" id="area-contract">
Text parsing in corelib is **combinator-first**: a byte-indexed cursor, primitive parser combinators, and **Pest `.pest` grammars** compiled to Beskid combinator parsers by the [Pest parser generator](/platform-spec/compiler/compiler-mods/pest-parser-generator/) mod. Regex matching is **not** a separate engine — it is a generated parser from canonical `regex.pest`.
</SpecSection>

<SpecSection title="Responsibility boundaries" id="responsibility-boundaries">
- **In scope:** `Core.Text.Cursor`, `Core.Text.Parser`, `Core.Text.Regex`, generated parsers for embedded DSLs (console markup, regex patterns).
- **Out of scope:** Beskid surface syntax parsing ([`beskid.pest`](/platform-spec/compiler/front-end/parser-and-ast-contracts/)); full CommonMark ([ADR D-CORE-TERM-0030](/platform-spec/core-library/terminal-and-console/console-markup-format/adr/0030-markup-not-full-commonmark/)).
</SpecSection>

<SpecSection title="Failure and diagnostics model" id="failure-and-diagnostics-model">
Parse failures return structured `ParseResult` errors at a byte offset with a rule label. Grammar codegen failures use diagnostic band **E18xx** (mod host). Runtime combinators **must not** panic on malformed input.
</SpecSection>
