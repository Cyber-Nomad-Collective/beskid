## Layering

| Layer | Responsibility |
| --- | --- |
| `System.Time.*` types | `Instant`, `Duration`, `Date`, `TimeOfDay`, `DateTime`, `TimeError` under `System/Time/` |
| `System.Time` hub | Clock reads, duration helpers, UTC conversions, ISO formatting/parsing |
| Runtime builtins | `__clock_realtime_nanos`, `__clock_monotonic_nanos` in `beskid_runtime` |
| Concurrency package | Fiber scheduling monotonic millis via `Concurrency.NowMillis` |

## Module layout

Types live one-per-file under `compiler/corelib/packages/runtime/src/System/Time/`. Hub functions remain in `System/Time.bd`, matching the `System.Syscall` split pattern.
