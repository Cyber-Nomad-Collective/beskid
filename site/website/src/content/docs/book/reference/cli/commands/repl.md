---
title: "beskid repl"
description: "Removed in 0.6.0. Use beskid dev repl."
---

The root command `beskid repl` was removed in version 0.6.0. Use `beskid dev repl` instead.

```bash
beskid dev repl --help
```

The REPL is experimental. It uses line-oriented input and output. Pass `--plain` to disable animated progress. Do not use its result as evidence for the AOT behavior of `beskid run`.
