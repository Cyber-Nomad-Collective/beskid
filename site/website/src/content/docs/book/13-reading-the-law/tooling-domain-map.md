Open the [Tooling hub](/docs/standard/capabilities/taxonomy--tooling/) for contracts around the commands, editor integrations, manifests, registries, and supporting tools that surround a Beskid project.

## Start from the task

| Task | Useful standard area |
| --- | --- |
| Invoke compiler commands | [CLI](/docs/standard/capabilities/taxonomy--tooling--cli/) |
| Configure a project or workspace | [Manifests and lockfiles](/docs/standard/capabilities/taxonomy--tooling--manifests-and-lockfiles/) |
| Work in an editor | [LSP](/docs/standard/capabilities/taxonomy--tooling--lsp/) |
| Consume or publish packages | [Registry client](/docs/standard/capabilities/taxonomy--tooling--registry-client/) |

The [Book reference](/book/reference/) is the practical companion for command walkthroughs. Follow the standard link whenever a workflow depends on a contract rather than a local convenience.
