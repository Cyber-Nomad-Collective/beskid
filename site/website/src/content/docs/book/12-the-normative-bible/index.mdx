Every language project eventually grows a Google Doc titled "FINAL spec v3 (real)." Beskid skipped that stage and went straight to **[Platform specification](/platform-spec/)**—one tree, Git as the version axis, and ADRs instead of hallway folklore.

This book is **informative**. When we argue, we argue against the spec—not against a README paragraph from 2019.
