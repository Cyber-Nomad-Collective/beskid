## A first program

```beskid
use Core.Output;

i32 Main()
{
    mut i64 total = 0;
    i64[] numbers = [1, 2, 3];
    for n in numbers
    {
        total += n;
    }
    Output.WriteLine("total: ${total}");
    return 0;
}
```

The return type comes first (`i32 Main()`), a local is declared with its type (`mut i64 total`), `mut` allows it to change, an array literal uses square brackets, and `${...}` puts a value into a string. `Main` returns the exit code of the process.

## By the end of this chapter

- Pick the right primitive type and write its literal, including strings with escapes and interpolation.
- Read an expression with several operators and know what binds first.
- Change a value with `=` or `+=`, and know why the compiler asks for `mut`.
- Write `if`, `while` and `for` in the house style.
- Declare a struct, build one with a literal, and branch on an enum with `match`.
