Every language project eventually grows a Google Doc titled "FINAL spec v3 (real)." Beskid skipped that stage and went straight to **[Platform specification](/platform-spec/)**: one tree, Git as the version axis, ADRs instead of hallway folklore.

This book is **informative**. When we argue, we argue against the spec, not against a README paragraph from 2019.

<Aside type="tip">

If you cannot link a behavior to a **Standard** spec page (or a Proposed page you label as such), you are documenting wishful thinking.

</Aside>
