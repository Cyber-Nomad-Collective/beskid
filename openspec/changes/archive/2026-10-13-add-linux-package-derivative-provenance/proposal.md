## Why

The corrected 0.5.2 Linux DEB needs independently qualified provenance without
rewriting immutable three-platform native release evidence or extending the
native Woodpecker publisher.

## What Changes

- Add a release-policy requirement for a bounded Linux package derivative.
- Bind a finite correction intent to one native release, one distribution
  recipe, one DEB, and parseable RED/GREEN qualification evidence.
- Require append-only immutable-tag publication with verified idempotency and
  partial-attempt recovery.

## Impact

This changes release-policy obligations only. Native aggregate schemas,
Woodpecker lanes, credentials, rolling tags, and non-Linux package paths are
unchanged.
